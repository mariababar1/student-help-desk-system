# Lab 02 — Git and GitHub Workflow

## Aim
Practice version control and upload the Student Help Desk System files to GitHub.

## Procedure
1. Sign in at https://github.com.
2. Create a repository named `Student-Help-Desk-System`.
3. Add a description and choose visibility according to course requirements.
4. Upload the project proposal, lab folders, diagrams, and website source.
5. Enter a commit message such as `Add SCD lab task materials`.
6. Click **Commit changes**.
7. Copy the repository URL and capture a screenshot showing the repository and files.

## Suggested repository structure
```text
Student-Help-Desk-System/
├── Project_Proposal.pdf
├── SCD_Lab_Tasks/
├── Diagrams/
│   ├── UseCaseDiagram.png
│   └── ClassDiagram.png
└── README.md
```

## Evidence to save
- Screenshot of the repository home page.
- Actual repository URL in `GitHub-Repository-Link.txt`.

## Note
Do not write a made-up URL. Save the real URL after creating your repository.
