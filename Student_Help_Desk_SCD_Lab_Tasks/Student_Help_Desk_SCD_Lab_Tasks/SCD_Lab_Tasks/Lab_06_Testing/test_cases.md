# Lab 06 — Testing and Debugging

## Aim
Test the Student Help Desk prototype's forms using positive and negative test cases.

| ID | Page | Test input | Expected result |
|---|---|---|---|
| TC-01 | Registration | Submit all fields empty | Required/validation errors appear |
| TC-02 | Registration | Invalid email such as `abc` | Email error appears |
| TC-03 | Registration | Password shorter than 8 characters | Password error appears |
| TC-04 | Registration | Different password and confirmation | Password mismatch error appears |
| TC-05 | Registration | Valid-format inputs and terms checked | Demo validation success message appears |
| TC-06 | Login | Invalid email | Email error appears |
| TC-07 | Login | Valid-format email and password | Message says server authentication is not connected |
| TC-08 | Contact Us | Subject shorter than 3 characters | Subject error appears |
| TC-09 | Contact Us | Message shorter than 10 characters | Message error appears |
| TC-10 | Contact Us | All valid-format fields | Demo validation success message appears |
